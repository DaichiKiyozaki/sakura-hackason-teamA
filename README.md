# 面接評価支援システム

## 目的

- 面接内容の記録と整理にかかる時間を減らす
- 面接官が同じ評価基準を使えるようにする
- 面接内容と評価理由をあとから確認できるようにする
- 面接内容や評価結果をCSV形式で管理・出力できるようにする

AIは面接内容の整理と要約に使用し、合否を自動で決定しません。

## 作る機能

```text
面接内容を文字として入力
        ↓
質問と回答に分割
        ↓
回答を短く要約
        ↓
面接官が評価項目ごとに5段階評価
        ↓
面接内容と評価のサマリーを表示
        ↓
CSV形式で保存・出力
```

### 機能一覧

- 面接内容の文字入力
- 面接官の質問と応募者の回答の分割
- 応募者の回答の要約
- 評価項目ごとの5段階評価
- 評価理由と所感の入力
- 面接内容と評価結果のサマリー表示
- 過去の面接記録との比較
- CSV形式でのデータ管理・出力

## システム構成

```text
TypeScriptフロントエンド
        ↓
FastAPIバックエンド
        ↓
Ollama / Qwen3
        ↓
質問・回答の分割と回答の要約
        ↓
フロントエンドで表示・評価
        ↓
CSVへ保存・出力
```

## データ管理

開発中はCSVファイルを使用して、以下の情報を管理する予定です。

- 面接を識別するID
- 面接日
- 応募者名またはデモ用の識別名
- 質問
- 回答
- 回答の要約
- 評価項目
- 評価点
- 評価理由・所感

CSVのファイル名、列名、ファイルの分け方は未定です。
文字コードはUTF-8を使用します。
